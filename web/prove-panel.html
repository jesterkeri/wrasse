Step two, and it costs nothing

2. Take the memory away, and watch it stop working

Everything above could be a program with two prices written into it. This is how you tell the difference. It takes the memory away from the two agents this page is serving and asks them for the same quote again, four times over: once with nothing broken, then with both memory files deleted, then with one that will not open, then with a single character of one transaction hash changed. The first has to produce terms and the other three have to refuse, because a build that refuses everything proves nothing either.

It runs on a throwaway copy in a temporary directory, which is deleted afterwards. The memories themselves are read to be copied and never written, so this changes nothing for the next person to open the page. Nothing is signed and no money moves.
